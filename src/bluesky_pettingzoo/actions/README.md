# actions/

动作空间管理模块，负责将 RL Agent 输出的连续/离散动作翻译为 BlueSky 仿真引擎可执行的命令流。

## 文件说明

| 文件 | 用途 |
|------|------|
| `translator.py` | 动作翻译器，将 RL 动作转换为 BlueSky 命令（HDG, ALT, SPD） |

## 设计要点

- 支持连续动作空间（航向角、高度、速度的连续值）
- 支持离散动作空间（预定义的动作选项）
- 所有 Agent 的动作在 `step()` 中打包为一条命令流一次性写入 BlueSky，保证时序一致性

## 扩展方式

新增动作类型时，在 `translator.py` 中添加对应的翻译方法，并在 `envs/scenarios/` 的场景中注册新的动作空间。
